# Changelog

## 0.1.3

First release. The linter was introduced in the GRAPH-GRPO-LEX paper and developed in the [graph-grpo-lex](https://github.com/moriyadechtiar/graph-grpo-lex) research repository.

- Graph metrics, checks, context slicing and reference-free scores.
- The default ontology can be extended with additional node types, edge types and connections.
- Command line: `contract-graph-linter graph.json`.
- Four bundled examples: `contract-graph-linter --example nda`.
- An evaluation with planted defects, in `evaluation/`.
